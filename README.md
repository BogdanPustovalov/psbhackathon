# Юридический ассистент — кейс ПСБ, Hack&Change 2026

Веб-ассистент, который отвечает на юридические вопросы сотрудников компании **только по
документам базы знаний**: договорам, внутренним регламентам и выдержкам из законов.
Каждый ответ ссылается на конкретные пункты, а интерфейс показывает подтверждающие
фрагменты прямо в тексте документа.

Что умеет ассистент:

- отвечает со ссылками `[1]`, `[2]` на пункты договоров, регламентов и статьи законов;
- прямо говорит, чего не хватает в базе, и не отвечает по памяти;
- замечает ошибку в вопросе (например, неверную сумму из договора);
- учитывает редакцию документа на дату события и предупреждает об утративших силу редакциях;
- задаёт уточняющий вопрос, если контрагент или договор неоднозначен;
- ведёт диалог с учётом истории сообщений.

## Быстрый старт

Нужен Docker с Compose v2.24 или новее.

```bash
cp .env.example .env    # затем впишите ключ API в LLM_API_KEY
docker compose up --build
```

| Что | Адрес |
|---|---|
| Интерфейс | http://localhost:8080 |
| API (Swagger) | http://localhost:8000/docs |
| Проверка API | http://localhost:8000/health |

Остановить: `docker compose down`.

### Демо-режим без ключа и бэкенда

Интерфейс можно показать на встроенных примерах ответов, не подключая модели:

```bash
FRONTEND_USE_MOCK=1 docker compose up --build --no-deps frontend
```

В шапке появится метка «Демо-данные». Ответы подготовлены для примеров вопросов
на стартовом экране.

## Переменные окружения

Все переменные описаны в [`.env.example`](.env.example). Файл `.env` с ключами в репозиторий
не попадает (он в `.gitignore`).

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_BASE_URL` | — | Базовый адрес OpenAI-совместимого API организаторов |
| `LLM_API_KEY` | — | Ключ API; один ключ для генерации, эмбеддингов и реранкера |
| `LLM_MODEL` | `deepseek/deepseek-v4.1-flash` | Генеративная модель |
| `EMBEDDING_MODEL` | `baai/bge-m3` | Модель эмбеддингов |
| `RERANKER_ENABLED` | `true` | Включить реранкер |
| `RERANKER_MODEL` | — | Модель реранкера (Qwen3 Reranker 8B, идентификатор — из инструкции организаторов) |
| `CHROMA_PERSIST_DIRECTORY` | `/app/data/chroma` в Docker | Каталог векторной базы Chroma |
| `CHROMA_COLLECTION` | `documents` | Коллекция Chroma |
| `API_PREFIX` | `/api/v1` | Префикс API |
| `BACKEND_CORS_ORIGINS` | `http://localhost:5173,http://localhost:8080` | Разрешённые источники запросов к API |
| `BACKEND_PORT` | `8000` | Порт API на хост-машине |
| `FRONTEND_PORT` | `8080` | Порт интерфейса на хост-машине |
| `FRONTEND_USE_MOCK` | `0` | `1` — интерфейс работает на встроенных демо-ответах |

### Внешние API и подключение ключа

Ассистент использует API организаторов хакатона (OpenAI-совместимый, авторизация
`Authorization: Bearer <LLM_API_KEY>`):

| Задача | Модель | Эндпоинт |
|---|---|---|
| Генерация ответа | DeepSeek V4.1 Flash | `POST {LLM_BASE_URL}/chat/completions` |
| Эмбеддинги | BAAI/bge-m3 | `POST {LLM_BASE_URL}/embeddings` |
| Реранжирование | Qwen3 Reranker 8B | `POST {LLM_BASE_URL}/rerank` |

Чтобы подключить ключ: скопируйте `.env.example` в `.env`, впишите адрес в `LLM_BASE_URL`
и ключ в `LLM_API_KEY`, затем перезапустите `docker compose up`. Не вставляйте ключи
в код, README и коммиты.

## Архитектура

```
Браузер ──► frontend (nginx :80 → хост :8080)
              ├── /            статический интерфейс (React + Vite)
              └── /api/*  ──►  backend (FastAPI :8000)
                                 ├── retrieve: bge-m3 → Chroma
                                 ├── rerank:   Qwen3 Reranker
                                 └── generate: DeepSeek V4.1 Flash
```

- **frontend/** — React + TypeScript, собирается Vite и раздаётся nginx. nginx проксирует
  `/api/` на бэкенд, поэтому браузер обращается к одному адресу и CORS не нужен.
- **backend/** — FastAPI: поиск фрагментов, реранжирование, генерация ответа со ссылками.
  Подробнее — [docs/architecture.md](docs/architecture.md).
- Формат API между интерфейсом и бэкендом — [docs/api.md](docs/api.md).

Интерфейс:

- чат с историей диалога (сохраняется в браузере);
- метка достоверности ответа: «Подтверждено: N источников», «Ответ неполный»,
  «Ответа нет в базе знаний», «Нужно уточнение»;
- блоки «Чего нет в базе знаний» и «Редакции документов»;
- карточки источников; клик по `[n]` или карточке открывает документ с подсвеченным
  фрагментом;
- список всех документов базы (кнопка «Документы»);
- уточняющий вопрос с кнопками вариантов.

## Порядок проверки основного сценария

1. Запустите `docker compose up --build` и откройте http://localhost:8080.
2. Нажмите пример вопроса «Какая арендная плата по договору с ООО «Северный Склад»…».
   Ответ должен содержать сумму, срок оплаты и ссылки `[1]`–`[3]`.
3. Нажмите на `[1]`: справа откроется договор аренды А-08/2024 с подсвеченным п. 3.1.
4. Задайте вопрос с ошибкой: «Почему по договору с ООО «Северный Склад» арендная плата
   500 000 рублей в месяц?» — ассистент укажет на неточность.
5. Спросите «Договор на 12 млн рублей заключали в августе 2024 года. Нужно ли было одобрение
   генерального директора?» — ответ опирается на редакцию регламента 2023 года, интерфейс
   предупредит, что она утратила силу.
6. Спросите «Подскажите гарантию по договору с «Альфой»» — ассистент уточнит контрагента;
   выберите вариант кнопкой.
7. Спросите «Какой размер пособия по беременности и родам?» — ассистент скажет, что
   в базе нет таких документов.

## Разработка без Docker

```bash
# Бэкенд
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload

# Интерфейс (Node.js 20.19+)
cd frontend
npm ci
npm run dev        # http://localhost:5173, обращается к http://localhost:8000/api/v1
npm run dev:mock   # то же, но на встроенных демо-ответах
```

## Зависимости

- Интерфейс: версии зафиксированы в [`frontend/package-lock.json`](frontend/package-lock.json).
- Решение для автоматической проверки: [`requirements.txt`](requirements.txt).
- Бэкенд: [`backend/pyproject.toml`](backend/pyproject.toml).

## Известные ограничения

- Бэкенд-пайплайн (поиск → реранкер → генерация) ещё подключается: пока он не готов,
  интерфейс можно проверить в демо-режиме.
- Версии зависимостей бэкенда в `backend/pyproject.toml` указаны как минимальные (`>=`),
  а не зафиксированные.
- Ассистент отвечает только по документам из базы знаний; вопросы вне базы он честно
  отклоняет.
- История диалога хранится только в браузере пользователя.
